claude-logbook

Browse, export and share your Claude Code sessions from the terminal.

Install

pipx install claude-logbook      # or: pip install --user claude-logbook
claude-logbook                   # table of every session

Share a session

Pick a session by its number in the table or by a prefix of its UUID, then share it:

claude-logbook -s 3 --share                # asks before uploading
claude-logbook -s 5d10f1ee --share --expire 7d
claude-logbook -s 3 --share --images       # with its images
claude-logbook --shares                    # what you have shared
claude-logbook --unshare 5d10f1ee          # take it down

Sharing the same session again updates it in place: the link stays the same.

Links

{{PUBLIC_URL}}/share/<id>the conversation as a page
{{PUBLIC_URL}}/share/<id>.txtplain text transcript
{{PUBLIC_URL}}/share/<id>.jsonthe raw data, as claude-logbook --json -s prints it

Before you share

A share holds the whole conversation: your prompts, Claude's answers, the tool calls and the project path. Anyone with the link can read it. It is not encrypted, and this server can read it too.

  • --share warns if it spots things that look like API keys, tokens or private keys.
  • Images go only with --images, and nothing checks what they show: look at them first.
  • Shares expire after 30 days unless you pick --expire 1d, 7d or 90d.
  • Only the machine that created a share holds its secret and can update or delete it (~/.local/state/claude-logbook/shares.json).
  • Share pages are marked noindex, but a link is only as private as the places you paste it.

API

The CLI talks to a small JSON API; you can use it directly:

POST   /api/shares          {"payload": {...}, "expire": "30d"}  → {id, url, secret, expires}
PUT    /api/shares/<id>     Authorization: Bearer <secret>        replace the content
DELETE /api/shares/<id>     Authorization: Bearer <secret>        delete it

The payload is the JSON of claude-logbook --json -s REF, one session. The server builds the page itself and does not accept HTML.
